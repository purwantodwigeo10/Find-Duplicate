# Changelog

All notable changes to Find Duplicate are documented here.

## 26.1.0 - Qt compatibility revision, 2026-09-21

- Correct Qt5 field types to QVariant.String and QVariant.Int.
- Retain QMetaType.Type field types for Qt6.
- Include scoped enum, exec(), QAction and V3 writer fixes from 26.1.1.

## 26.1.0 - 2026-09-13

- Improved duplicate and unique value identification for point, line, and
  polygon layers.
- Refined output fields, frequency and location summaries, and safe Shapefile
  replacement.
- Added sample data and clearer usage documentation.

## 0.26.01

- Added folder-based vector input.
- Added Select All and Unselect All for optional retained fields.
- Preserved the `FIDU` product code and `SW` fixed code.
